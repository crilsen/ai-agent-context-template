# Security Review Workflow

1. Read `AGENTS.md`, architecture, decisions, conventions, and the requested scope.
2. Do not modify files automatically.
3. Assess applicable IAM/RBAC, least privilege, credentials, secrets, exposure, network boundaries, firewall rules, encryption, storage, Kubernetes security, workload identity, CI/CD, supply chain, dependencies, IaC state, logging, auditing, images, and container privileges.
4. Report only evidence-based findings, prioritized by severity.
5. For each finding provide: issue, impact, evidence, and recommendation.
