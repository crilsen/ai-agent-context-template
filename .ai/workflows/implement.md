# Implementation Workflow

1. Read `AGENTS.md`; understand the requested outcome.
2. Read the relevant `.ai/` context and identify files, dependencies, and impact.
3. Implement the smallest necessary change, following existing conventions.
4. Do not change unrelated code, run destructive commands, or deploy without explicit authorization.
5. Stop and report if an undocumented architectural decision is required.
6. Run applicable checks from `.ai/VALIDATION.md`, fix failures within scope, and report limitations.
7. Update `.ai/TASKS.md` when work state changes and `.ai/HANDOFF.md` after relevant work.
8. Summarize files changed, validation, unresolved issues, and next actions.
